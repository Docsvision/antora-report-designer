= Установка модуля {rd}

. Запустите файл `ReportSolution.msi` -- запущен мастер установки {dv} 5 ReportService. Нажмите на кнопку *Далее*.
+
.Приветственное окно мастера установки
image::install-hello.png[Приветственное окно мастера установки]
+
. Ознакомьтесь с лицензионным соглашением, примите условия, нажмите кнопку *Далее*.
+
.Лицензионное соглашение мастера установки
image::install-license.png[Лицензионное соглашение мастера установки]
+
. Выберите конфигурацию установки и нажмите кнопку *Далее*.
+
.Выбор конфигурации установки
image::install-components.png[Выбор конфигурации установки]
+
. Нажмите кнопку *Установить*.
+
.Окно подтверждения установки
image::install-confirm.png[Окно подтверждения установки]
+
. Дождитесь окончания установки и нажмите кнопку *Готово*.
