= Предварительная настройка модуля "{rd}"

Настройка доступа к справочникам выполняется в {wincl}е по средствам дискреционной модели безопасности справочников.

По умолчанию пользовательский функционал доступен всем, настройка модуля доступна пользователям, входящим в группу *{dv-admins-serv}*.

.Настройка доступа к справочнику
image::directory-access.png[Настройка доступа к справочнику]

Для корректной работы с конструктором справочников в {wincl}е в конструкторе разметок внесите изменения в разметку "Карточка строки справочника -- Подключения". Удалите из разметки элемент `BTL_Connection`. Добавьте на разметку новый элемент _Строка_ и в параметрах укажите _Источник данных_ -- Подключение, а _Элемент данных_ -- Строка подключения, сохраните изменения.

В {wincl}е откройте Редактор метаданных и измените тип поля `RD_Function` с `String` на `Text`.

.Настройка разметки в {wincl}е
image::layout-setting.png[Настройка разметки в {wincl}е]

Добавление справочника в {wc} происходит автоматически при установке модуля. При отсутствии модуля _отчёты_ в {wc}е, добавьте его вручную. В программе {kvr} в разметку _DV.MainMenu_ добавьте ЭУ `_Ссылка_`. Поле _Адрес_ заполните значением `#/RowView/4538149d-1fc7-4d41-a104-890342c6b4f8/a1dce6c1-db96-4666-b418-5a075cdb02c9/b6e5840c-92a0-4578-8a43-2f76159225c6`.

.Добавление справочника в {wc}
image::kvr.png[Добавление справочника в {wc}]

В программе {kvr}, в разметке menu:BackOffice справочники[Конструктор справочников > Узлы Справочника] найдите решение _Конструктор отчётов_ и установите его в качестве активного.
