= Настройка отчёта

Создание и настройка отчёта может проходить как в {wc}е, так и в {wincl}е.

.Создание отчёта предполагает выполнения нескольких шагов:
. Настроить подключения источников данных.
. Создать шаблон отчёта и карточку файла шаблона отчёта.
. Создать и настроить отчёт.

[#connections]
== Настройка подключений источников данных

Для настройки подключений источников данных откройте раздел (узел) _Подключения_ в {wc}е в разделе _отчёты_.

.Раздел "Подключения"
image::connections.png[Раздел "Подключения"]

После установки модуля автоматически будет создано подключение к основной используемой базе {dv}. Оно будет отображаться под названием "DB {dv}". Изменить или удалить такое подключение невозможно.

.Стандартное подключение "DB {dv}"
image::connections.png[Стандартное подключение "DB {dv}"]

.Создайте новое подключение, заполните:
. Название -- используется для отображения названия подключения при настройке Источников данных в отчёте.
. Описание -- используется, как поясняющее назначение текущей строки подключения.
. Строка подключения -- используется для хранения настройки подключения к БД, задается в https://learn.microsoft.com/ru-ru/dotnet/framework/data/adonet/connection-string-syntax[формате "ADO.NET"].
+
.Шаблон строки подключения:
 Data Source=<имя сервера СУБД>;Initial Catalog=<название БД DV или любой другой >;User ID=<логин >;Password=<пароль>;Integrated Security=False;
+
.Строка подключения к базе данных:
[%collapsible]
====
{blank}::
include::5.5.1@mgmtconsole:admin:install.adoc[tags=string]
====
+
. Не используется -- флаг, отражающий возможность использования данного подключения при настройке _отчётов_.
+
.Настройка подключений источников данных
image::data-sources.png[Настройка подключений источников данных]
+
. Инвариативное имя провайдера -- используется для хранения названия провайдера БД, отличного от Microsoft SQL Server, в формате "ADO.NET".

== Проверка введённых данных

При попытке сохранить подключение будет произведена проверка введённых данных. Если данные некорректны, в правом нижнем углу страницы появится информация об ошибке подключения.

.Ошибка подключения
image::connection-error.png[Ошибка подключения]

Если данные корректны, в правом нижнем углу страницы появится информация об успехе подключения.

.Успешно подключено
image::connection-ok.png[Успешно подключено]

Все существующие подключения можно просмотреть в разделе "Подключения".

.Раздел "Подключения"
image::connections.png[Раздел "Подключения"]

[#report-template]
== Создание шаблона отчёта

Шаблон отчёта -- файл, в котором определяется, внешний вид отчёта, расположение элементов, источники данных и логика формирования содержимого.

Настройка шаблона происходит в зависимости от выбранного провайдера. Для создания шаблонов отчётов провайдера `FastReport` используйте конструктор "Fast Report Designer" (см. https://www.fast-report.com/public_download/docs/FRVCL/FRVCLUserManual-ru.pdf[документацию FastReport 4.6]).

Для провайдера `FastReport` загрузка шаблона происходит путем создания РК вида "Файл" и добавления файла расширения `.frx` в созданную карточку. Далее этот шаблон отчёта будет использоваться при настройке отчёта в {dv}.

.Загруженный файл шаблона в карточку
image::report-template-web.png[Загруженный файл шаблона в карточку]

[#create-report]
== Создание и настройка отчёта

Для настройки самого отчёта, откройте раздел (узел) _Настройка отчётов_ в {wc}е в разделе _отчёты_ и нажмите кнопку создания отчёта, image:webclient:user:buttons/blue-plus.png[Синий плюс].

.Карточка отчёта
image::report-card.png[Карточка отчёта]

.Чтобы создать отчёт, заполните:
. Название -- используется для идентификации отчёта для пользователей на вкладках _отчёты_ и _Настройка отчётов_.
. Провайдер -- механизм, отвечающий за генерацию файла отчёта. Доступны следующие провайдеры:
+
* _FastReport_ -- формирование отчёта выполняется на уровне сервера приложений {dv} средствами библиотеки `FastReport.OpenSource`.
* _Microsoft SQL Server Re-porting Services_ -- формирование отчета выполняется на внешнем сервере генерации отчетов.
* _BTLabReportServer_ -- формирование отчета выполняется на внешнем сервере генерации отчетов.
+
. Шаблон отчёта -- при использовании провайдера "FastReport" выберите карточку вида _Файл_ с загруженным файлом шаблона. При использовании других провайдеров генерации отчётов, файл шаблона загружать в {dv} не требуется, если шаблон отчёта хранится на сервере генератора отчётов.
. Выполнять в фоновом процессе -- при установке флага отчёт будет формироваться в асинхронном режиме, направляя задания с результатом инициатору.
. Данные отчёта -- выборки, значения которых будут отображены в сформированном отчёте.
+
* Имя источника в шаблоне -- наименование источника данных, указанное в файле шаблона отчёта FastReport.
* Тип источника данных -- определяет тип источника SQL или API. Работа с типом источника API описана в разделе "xref:api-source.adoc[Источник данных API]".
* Подключение -- ссылка на строку подключения к базе данных. Используется при "Типе" источника данных SQL.
* Функция -- текст SQL запроса или название метода при "Типе" источника данных API.
. Параметры отчёта -- табличная часть, отражающая переменные, необходимые для ограничения выборки данных отчёта. Отчёт может не содержать параметров, в таком случае отчёт будет сформирован без вызова автогенерируемой формы ввода параметров.
* Параметр -- тип ЭУ параметра, отображаемого на форме ввода параметров отчёта, см. раздел "xref:format.adoc#preconfigured[Преднастроенные параметры]".
* Название -- наименование параметра, отображаемое на форме ввода пара-метров отчёта.
* Текст метки -- содержимое метки, отображаемой слева от ЭУ параметра.
* Подсказка -- содержимое всплывающей подсказки.
* Узел конструктора справочника -- узел Конструктора справочников, который будет использоваться для выбора строки справочника при выборе значения параметра. Используется для ЭУ `_Строка конструктора справочников_`.
* Обязательность -- флаг, указывающий на обязательность заполнения параметра.
* Скрытый -- флаг видимости параметра на форме (для передачи в отчёт параметров без необходимости их заполнения пользователем).
* Свойства -- настройка свойств для ЭУ параметров отчёта, к примеру свойство `*default*` - определяет значение по умолчанию для ЭУ. Примеры настройки см. в разделе "xref:format.adoc#preconfigured[Преднастроенные параметры]".
