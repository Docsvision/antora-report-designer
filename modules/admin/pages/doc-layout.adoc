= Настройка разметки документа

Модуль "{rd}" позволяет генерировать отчёты прямо из карточки доку-мента. Для этого в программе {kvr} откройте разметку любого вида документа и добавьте на неё элемент управления `_Кнопка загрузки отчета из документа_`.

.ЭУ "Кнопка загрузки отчета из документа"
image::report-button.png[ЭУ "Кнопка загрузки отчета из документа"]

После добавления кнопки, в окне _Свойства_ укажите её текст, в качестве свойства *Отчет* или *Шаблон* укажите `RowID` строки справочника _Отчеты_.

.Свойства кнопки загрузки отчёта из документа
image::report-button-props.png[Свойства кнопки загрузки отчёта из документа]

Чтобы передать в качестве параметров отчёта значения из карточки документа, в свойстве *Тег* укажите сопоставление названия параметра отчёта и атрибут карточки в следующем формате: `название_параметра: название_секции.название_поля`.

.Пример передачи значений из карточки в параметры отчета
image::tag-property.png[Пример передачи значений из карточки в параметры отчета]

Сохраните web-разметку и перезагрузите IIS. Кнопка отобразится на разметке документа.
