= Особенности провайдеров

В модуле "{rd}" реализована поддержка следующих провайдеров:

* BTLabReportServer
* Microsoft SQL Server Reporting Services
* FastReport

Для использования провайдера BTLabReportServer откройте раздел (узел) «Провайдеры» в {wc}е в разделе «Отчеты». Создайте новую запись, указав URL-адрес сервера генерации отчётов и токен.

.Провайдер "BTLabReportServer"
image::report-server.png[Провайдер "BTLabReportServer"]

Для использования провайдера Microsoft SQL Server Reporting Services откройте раздел (узел) «Провайдеры» в Web-клиенте в разделе «Отчеты». Создайте новую запись, указав URL-адрес сервера генерации отчётов, а также логин и пароль пользователя сервера гене-рации отчётов.

.Провайдер "Reporting Services"
image::edit-provider-rep-serv.png[Провайдер "Reporting Services"]

При генерации отчётов с использованием провайдера FastReport учитывайте особенности вывода различных форматов.

* В PDF-версии отчёта, изображения будут корректно загружены и отображены.
* В HTML-версии отчёта изображения могут отсутствовать или не отображаться корректно.

К особенностям FastReport Open Source (Community) относится, отсутствие поддержки инфографики. Это означает, что элементы визуализации данных, такие как диаграммы и графики, недоступны в данной версии. Для использования этих возможностей потребуется переход на коммерческую редакцию FastReport. Прочие ограничения смотрите на https://fastreports.github.io/FastReport.Documentation/COMPARISON.html[сайте проекта].
