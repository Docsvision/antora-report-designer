= Настройка разметки папки

Также модуль "{rd}" позволяет генерировать отчёты прямо из папки. Для этого в программе {kvr} откройте разметку папки и добавьте на неё элемент управления `_Кнопка загрузки отчета из папки_`.

.ЭУ "Кнопка загрузки отчета из папки"
image::folder-button-control.png[ЭУ "Кнопка загрузки отчета из папки"]

После добавления кнопки в окне _Свойства_ укажите её текст, в качестве свойства *Отчет* укажите `RowID` строки справочника _Отчеты_. Установите флаг _Только загруженные документы_, если отчёт должен генерироваться только по документам, которые отображаются в папке.

.Свойства кнопки загрузки отчета из папки
image::report-button-props.png[Свойства кнопки загрузки отчета из папки]

Чтобы передать значения атрибутов карточки в параметры отчёта, в разделе _Свойства_ в свойстве *Тег* укажите явное сопоставление параметров со значениями в карточке. Например, для использования даты регистрации документа в качестве параметра отчёта `Date` укажите в свойстве *Тег* соответствие.

.Передача даты регистрации документа в качестве параметра отчёта "Date"
image::folder-tag.png[Передача даты регистрации документа в качестве параметра отчёта "Date"]

Сохраните разметку и перезагрузите IIS. Кнопка отобразится на разметке папки.

image::folder-button.png[Пример кнопки формирования отчета из папки]
